Règles de confidentialité

Carnet Budget · mise à jour le 11 novembre 2026

En bref : Carnet Budget n'a pas de serveur. Vos données restent sur votre appareil et, si vous l'activez, dans un seul fichier de votre propre Google Drive. Personne d'autre, y compris l'éditeur de l'application, n'y a accès.

1. Qui sommes-nous

Carnet Budget est une application web personnelle et gratuite de suivi de budget, publiée sur geoffreyofficial.github.io/Budget. Elle ne contient ni publicité ni outil de mesure d'audience.

2. Données que vous saisissez

Revenus, dépenses, catégories, budgets, épargne et préférences d'affichage. Ces données sont enregistrées uniquement dans le stockage local de votre navigateur (localStorage), sur votre appareil. Elles ne sont jamais envoyées à un serveur de l'éditeur.

3. Sauvegarde Google Drive (facultative)

Si vous appuyez sur « Connecter Google Drive », l'application vous demande l'autorisation drive.file. Cette autorisation est volontairement limitée :

  • l'application ne peut voir et modifier que les fichiers qu'elle a créés elle-même, en pratique un seul fichier nommé budget-backup.json ;
  • elle n'a aucun accès à vos autres fichiers, documents ou photos Google Drive ;
  • elle lit l'adresse e-mail du compte connecté, uniquement pour l'afficher dans les réglages afin que vous sachiez quel compte est utilisé.

Les échanges se font directement entre votre navigateur et Google, de façon chiffrée (HTTPS). Le jeton d'accès délivré par Google est valable environ une heure et n'est conservé que sur votre appareil.

4. Utilisation des données Google

Les données obtenues via les API Google servent exclusivement à sauvegarder et restaurer votre propre budget. Elles ne sont ni vendues, ni partagées, ni transférées à des tiers, ni utilisées pour de la publicité, ni pour entraîner des modèles d'intelligence artificielle. L'utilisation des informations reçues des API Google respecte les Règles concernant les données utilisateur des services API Google, y compris les exigences d'utilisation limitée.

5. Autres connexions réseau

  • GitHub Pages héberge l'application ; comme tout hébergeur web, GitHub peut enregistrer des données techniques de connexion (adresse IP, navigateur).
  • Une fonctionnalité décorative (les photos affichées en touchant le chat) interroge l'API publique de GitHub pour lister les images du dossier de l'application. Aucune donnée de budget n'est transmise.

6. Conservation et suppression

  • Sur l'appareil : vos données restent tant que vous ne les effacez pas (bouton de réinitialisation de l'application ou effacement des données du site dans le navigateur).
  • Dans Google Drive : le fichier budget-backup.json est dans votre Drive ; vous pouvez le télécharger ou le supprimer à tout moment.
  • Révoquer l'accès : bouton « Se déconnecter » dans les réglages de l'application, ou depuis myaccount.google.com/permissions.

7. Cookies

L'application n'utilise pas de cookies. La connexion Google affiche une fenêtre fournie par Google, soumise aux règles de confidentialité de Google.
